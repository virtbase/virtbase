<Faq title="Häufig gestellte Fragen">
  <Question title="Wie lange dauert die Bereitstellung eines Servers?">
    Die Bereitstellung des gebuchten Pakets erfolgt in der Regel nach der Bestellung automatisch durch unser System ohne Wartezeit. Zusätzlich wird eine Bestätigung per E-Mail versendet.
  </Question>

  <Question title="Gibt es ein Traffic-Limit?">
    Nein, es gibt kein Traffic-Limit für unsere Server. Der Uplink wird nach dem Fair-Use-Prinzip bereitgestellt. Bei unverhältnismäßig hoher Dauernutzung kann die Bandbreite jedoch vorübergehend gedrosselt werden.
  </Question>

  <Question title="Kann das Paket später geändert werden?">
    Das gebuchte Paket kann einfach über das Kundenportal geändert werden. Bei einem Wechsel während des laufenden Abrechnungszeitraums wird die Preisdifferenz entsprechend gutgeschrieben.
  </Question>

  <Question title="Kann ich meinen Server jederzeit kündigen?">
    Ja, gebuchte Server können jederzeit über das Kundenportal gekündigt werden. Kündigungen werden zum Ende des ausgewählten Abrechnungszeitraums wirksam.
  </Question>

  <Question title="Wie kann ich auf meine Server zugreifen?">
    Der gebuchte Server kann über unser eigenes Kundenportal verwaltet werden. SSH-Zugriff per Passwort ist standardmäßig verfügbar. Der Server kann außerdem über die VNC-Konsole erreicht werden.
  </Question>

  <Question title="Wie sicher sind meine Daten?">
    Datenschutz hat für uns höchste Priorität. Alle Daten auf den Servern werden auf verschlüsselten Datenträgern gespeichert. Ein Zugriff durch uns als Anbieter oder durch andere Akteure ist grundsätzlich nicht möglich. Weitere Informationen findest du in unserer [Datenschutzerklärung](/de/legal/privacy).
  </Question>

  <Question title="Wo erhalte ich Support?">
    Unser Support-Team ist rund um die Uhr erreichbar. Sende eine E-Mail an [support@virtbase.com](mailto:support@virtbase.com), um schnell eine Antwort zu erhalten.
  </Question>

  <Question title="Wo befinden sich die Server?">
    Alle unsere Server befinden sich derzeit im Skylink Datacenter in den Niederlanden. Es ist nach Tier-3-Standards ausgestattet und verfügt über redundante Stromversorgung, Netzwerkkomponenten und Kühlung.
  </Question>
</Faq>
