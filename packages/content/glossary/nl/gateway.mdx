---
title: "Gateway"
description: "Het adres waarnaar een server al het verkeer voor andere netwerken stuurt: zijn weg naar internet."
---

Elke server heeft voor elke IP-versie een gateway nodig. Op de besturingssystemen die wij installeren, is die al voor je ingesteld; installeer je zelf een systeem, dan vul je hem met de hand in. De pagina <Ui>Overzicht</Ui> van een server toont de gateway bij elk adres.
