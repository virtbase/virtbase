---
title: "QEMU guest agent"
description: "Een kleine dienst in je server waarmee het klantenportaal dingen in het besturingssysteem kan uitlezen en wijzigen."
---

Dankzij de guest agent (`qemu-guest-agent`) kan Virtbase wachtwoorden resetten, schijfgebruik tonen, het besturingssysteem en een firewall in de server herkennen, en consistente [snapshots](#snapshot) maken. Hij is geïnstalleerd op elk besturingssysteem dat je kunt bestellen.

Zie [Wat betekenen de status, de aan/uit-knoppen en de grafieken van mijn server?](/nl/help/article/about-server-status#de-qemu-guest-agent)
