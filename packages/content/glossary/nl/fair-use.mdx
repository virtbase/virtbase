---
title: "Fair use"
description: "Onbeperkt dataverkeer, zolang het gebruik van een server op de lange termijn redelijk blijft."
---

Virtbase-servers hebben geen verkeerslimiet. Volgens het fair-useprincipe kan de snelheid van een server die langdurig buitensporig veel bandbreedte gebruikt tijdelijk worden beperkt, zodat hij de andere servers op dezelfde [uplink](#uplink) niet vertraagt.
