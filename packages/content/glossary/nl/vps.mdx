---
title: "Virtuele server (VPS)"
description: "Een eigen server die als virtuele machine op gedeelde hardware draait."
---

Een virtual private server gedraagt zich als een fysieke machine: hij heeft een eigen besturingssysteem, schijf, IP-adressen en root-toegang, maar deelt de fysieke host met andere servers. Virtbase-servers draaien op KVM, de virtualisatie die in Linux is ingebouwd.
