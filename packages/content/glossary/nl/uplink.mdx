---
title: "Uplink"
description: "De verbinding van de host waarop je server draait naar ons netwerk."
---

De uplink wordt gedeeld door de servers op een host: de maximale bandbreedte is voor hen samen beschikbaar. De pagina <Ui>Overzicht</Ui> toont onder <Ui>Nodedetails bekijken</Ui> de uplink van de host van je server.
