---
title: "Snapshot"
description: "Een back-upmodus die de schijf van een server kopieert terwijl de server blijft draaien."
---

In de modus <Ui>Snapshot</Ui> wordt de server niet onderbroken. Is de [QEMU guest agent](#guest-agent) geïnstalleerd, dan worden openstaande schrijfacties eerst naar de schijf weggeschreven, zodat de kopie consistent is.

Zie [Hoe maak ik een back-up van mijn server?](/nl/help/article/how-to-backup-server)
