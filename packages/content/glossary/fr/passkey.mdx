---
title: "Clé d'accès (passkey)"
description: "Un moyen de vous connecter avec votre empreinte digitale, votre visage, le code PIN de votre appareil ou une clé de sécurité, au lieu d'un mot de passe."
---

Une clé d'accès est enregistrée sur votre appareil et ne fonctionne que sur le site web pour lequel elle a été créée : elle ne peut donc être ni devinée ni dérobée par phishing. Vous pouvez ajouter plusieurs clés d'accès à votre compte Virtbase.

Consultez [Comment sécuriser mon compte avec l'authentification à deux facteurs et les clés d'accès ?](/fr/help/article/how-to-set-up-two-factor-authentication)
