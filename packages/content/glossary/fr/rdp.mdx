---
title: "RDP"
description: "Remote Desktop Protocol : le protocole qui vous permet de vous connecter au bureau d'un serveur Windows."
---

RDP affiche le bureau d'un serveur Windows sur votre ordinateur, de la même façon que [SSH](#ssh) vous donne une ligne de commande sous Linux. Il utilise le [port](#port) 3389, qui doit être ouvert dans le [pare-feu](#firewall). Les clients Bureau à distance sont intégrés à Windows et disponibles pour macOS, Linux et les téléphones.
