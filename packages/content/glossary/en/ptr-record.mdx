---
title: "PTR record"
description: "The DNS entry that tells which hostname belongs to an IP address: reverse DNS."
---

A normal DNS lookup turns a name such as `mail.example.com` into an address. A PTR record answers the opposite question, which is why it is called reverse DNS (rDNS). Mail servers check it before they accept email, so a server that sends mail needs one.

See [How do I set reverse DNS (PTR) for my server?](/en/help/article/how-to-set-reverse-dns)
