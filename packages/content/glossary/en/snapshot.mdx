---
title: "Snapshot"
description: "A backup mode that copies a server's disk while it keeps running."
---

In <Ui>Snapshot</Ui> mode, the server is not interrupted. With the [QEMU guest agent](#guest-agent) installed, pending writes are flushed to disk first, so the copy is consistent.

See [How do I back up my server?](/en/help/article/how-to-backup-server)
