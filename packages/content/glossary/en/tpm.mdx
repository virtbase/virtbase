---
title: "TPM"
description: "Trusted Platform Module: a security chip that keeps encryption keys safe and checks that a system starts untampered."
---

A TPM stores keys for features such as disk encryption and Secure Boot, so they cannot simply be copied off the disk. Windows 11 requires one.

Your server can have a virtual TPM: set the TPM to <Ui>v2.0</Ui> on the <Ui>Advanced</Ui> tab. Most Linux systems do not need it.
