---
title: "API key"
description: "A secret token that lets your own scripts and tools use the Virtbase API on your behalf."
---

An API key is sent with every request to the [Virtbase API](/en/help/article/how-to-use-public-api) in the `X-Virtbase-API-Key` header. Each key carries only the permissions you give it, for example reading invoices or managing backups, and is valid for one year.

Treat a key like a password: anyone who has it can do what its permissions allow.
