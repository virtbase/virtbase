---
title: "SSH"
description: "Secure Shell: the encrypted connection you use to log in to a Linux server and run commands."
---

You connect with `ssh root@<your-ip>` from a terminal. SSH uses [port](#port) 22 by default and authenticates you with a password or, more safely, an [SSH key](#ssh-key).

See [How do I connect to my server for the first time?](/en/help/article/how-to-connect-to-server)
