---
title: "IPv6 /64 subnet"
description: "A block of 18 quintillion IPv6 addresses that belongs to your server alone."
---

IPv6 addresses are longer than [IPv4](#ipv4) addresses, for example `2001:db8::10`. The `/64` means that the first 64 bits are fixed and the rest is yours: every Virtbase server gets a whole /64 and can use any address in it.

See [Which IP addresses does my server have?](/en/help/article/about-ip-addresses)
