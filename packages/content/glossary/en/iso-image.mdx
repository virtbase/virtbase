---
title: "ISO image"
description: "A file that contains a complete installation disc, used to install an operating system or boot a live system."
---

Mounting an ISO image on a server works like inserting a disc. You can install a system we do not offer, such as Windows or pfSense, or boot a live system to repair a server that does not start.

See [How do I install an operating system from my own ISO?](/en/help/article/how-to-install-from-iso)
