---
title: "IPv4 address"
description: "The classic internet address of a server, four numbers such as 203.0.113.10."
---

Every Virtbase server has one fixed IPv4 address, which stays the same for as long as you have the server. Additional IPv4 addresses are currently not available.

See [Which IP addresses does my server have?](/en/help/article/about-ip-addresses)
