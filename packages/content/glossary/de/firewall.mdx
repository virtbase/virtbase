---
title: "Firewall"
description: "Ein Filter, der entscheidet, welcher Datenverkehr einen Server erreichen und verlassen darf."
---

Vor jedem Virtbase-Server sitzt eine Firewall, die du im Kundenportal einstellst. Eine Firewall im Server selbst, etwa ufw oder firewalld, kann zusätzlich greifen; der Datenverkehr muss dann beide passieren.

Regeln erlauben oder blockieren Datenverkehr nach Richtung, [Port](#port), Protokoll und Quelladresse. Siehe [Wie richte ich die Firewall für meinen Server ein?](/de/help/article/how-to-use-server-firewall)
