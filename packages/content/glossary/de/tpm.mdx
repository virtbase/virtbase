---
title: "TPM"
description: "Trusted Platform Module: ein Sicherheitschip, der Schlüssel für die Verschlüsselung sicher aufbewahrt und prüft, dass ein System unverändert startet."
---

Ein TPM speichert Schlüssel für Funktionen wie Festplattenverschlüsselung und Secure Boot, sodass sie sich nicht einfach von der Festplatte kopieren lassen. Windows 11 setzt ein TPM voraus.

Dein Server kann ein virtuelles TPM haben: Stelle dafür im Reiter <Ui>Erweitert</Ui> das TPM auf <Ui>v2.0</Ui>. Die meisten Linux-Systeme brauchen es nicht.
