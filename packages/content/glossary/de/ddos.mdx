---
title: "DDoS-Angriff"
description: "Der Versuch, einen Server unerreichbar zu machen, indem man ihn von vielen Rechnern gleichzeitig mit Datenverkehr überflutet."
---

Ein DDoS-Angriff (Distributed Denial of Service) erzeugt so viel Datenverkehr, dass ein Server oder sein Netzwerk echten Besuchern nicht mehr antworten kann. Jeder Virtbase-Server ist ohne Aufpreis durch eine permanent aktive DDoS-Filterung geschützt.

Siehe [Welchen DDoS-Schutz nutzt Virtbase?](/de/help/article/about-ddos-protection)
