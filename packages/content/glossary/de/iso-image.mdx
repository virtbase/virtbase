---
title: "ISO-Image"
description: "Eine Datei mit dem Inhalt eines kompletten Installationsdatenträgers, mit der du ein Betriebssystem installierst oder ein Live-System bootest."
---

Ein ISO-Image in einen Server einzubinden, ist wie eine CD einzulegen. Du kannst ein System installieren, das wir nicht anbieten, etwa Windows oder pfSense, oder ein Live-System booten, um einen Server zu reparieren, der nicht startet.

Siehe [Wie installiere ich ein Betriebssystem von einer eigenen ISO?](/de/help/article/how-to-install-from-iso)
