---
title: "Virtueller Server (VPS)"
description: "Ein eigener Server, der als virtuelle Maschine auf gemeinsam genutzter Hardware läuft."
---

Ein Virtual Private Server verhält sich wie ein physischer Rechner: Er hat ein eigenes Betriebssystem, eine eigene Festplatte, eigene IP-Adressen und Root-Zugriff, teilt sich das physische Hostsystem aber mit anderen Servern. Virtbase-Server laufen auf KVM, der in Linux eingebauten Virtualisierung.
