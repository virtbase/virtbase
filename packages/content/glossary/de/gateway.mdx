---
title: "Gateway"
description: "Die Adresse, an die ein Server allen Datenverkehr für andere Netzwerke schickt – sein Weg ins Internet."
---

Jeder Server braucht für jede IP-Version ein Gateway. Auf den Betriebssystemen, die wir installieren, ist es bereits für dich eingerichtet; installierst du ein System selbst, trägst du es von Hand ein. Die Seite <Ui>Übersicht</Ui> eines Servers zeigt das Gateway neben jeder Adresse an.
