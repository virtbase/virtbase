Le bot Discord de Virtbase vous permet de gérer tous les serveurs que vous louez directement depuis Discord — les démarrer et les arrêter, créer des sauvegardes, modifier les règles de pare-feu, ouvrir une console — sans ouvrir le portail client.

Tout ce que le bot envoie n'est **visible que par vous**, même dans un salon partagé. Personne d'autre sur le serveur ne voit les noms de vos serveurs, vos adresses ou vos liens de console.

## Que peut faire le bot ?

| Domaine | Ce que vous pouvez faire |
| --- | --- |
| <Ui>Serveurs</Ui> | Voir tous les serveurs que vous louez, avec leur forfait, leur système d'exploitation, leur nœud et leurs adresses IP |
| <Ui>Alimentation</Ui> | Démarrer, redémarrer, éteindre, forcer l'arrêt ou réinitialiser matériellement, et consulter en direct l'utilisation du processeur, de la mémoire, du disque et du réseau |
| <Ui>Sauvegardes</Ui> | Créer, restaurer, verrouiller et supprimer des sauvegardes |
| <Ui>Pare-feu</Ui> | Consulter vos règles, en ajouter et en supprimer, et modifier les politiques par défaut |
| <Ui>DNS inversé</Ui> | Définir et supprimer le nom d'hôte vers lequel chacune de vos adresses renvoie |
| <Ui>Paramètres</Ui> | Renommer un serveur, le réinstaller avec un autre système d'exploitation, monter une image d'installation et consulter votre forfait |
| <Ui>Accès</Ui> | Ouvrir un lien de console à usage unique et réinitialiser le mot de passe administrateur |

Tout ce qui est payant — passer à un forfait supérieur, renouveler un serveur — vous renvoie vers le portail client. Le bot ne vous facture jamais rien.

## Comment ajouter le bot à mon serveur Discord ?

1. Lancez <Ui>/invite</Ui> sur n'importe quel serveur Discord où le bot est déjà présent, ou cliquez sur <Ui>Ajouter à Discord</Ui> sur la page [Sécurité](https://app.virtbase.com/account/settings/authentication) de votre compte.
2. Choisissez le serveur Discord auquel vous souhaitez l'ajouter.
3. Confirmez. Le bot demande uniquement l'autorisation d'envoyer des messages et de répondre aux commandes slash.

Vous n'avez pas besoin d'ajouter le bot à un serveur à vous. S'il est déjà présent sur un serveur dont vous êtes membre, vous pouvez l'y utiliser — ou lui envoyer un message privé.

## Comment lier mon compte Virtbase ?

Le bot ne peut pas savoir qui vous êtes à partir de votre seul compte Discord : les deux comptes doivent donc être liés une fois.

1. Ouvrez [Compte > Sécurité](https://app.virtbase.com/account/settings/authentication) dans le portail client.
2. Sous <Ui>Méthodes d'authentification</Ui>, cliquez sur <Ui>Lier</Ui> à côté de Discord et confirmez dans Discord.
3. Revenez sur Discord et lancez <Ui>/menu</Ui>.

C'est tout. À partir de là, le bot vous reconnaît sur tous les serveurs Discord où il est présent, ainsi qu'en message privé.

Si vous lancez <Ui>/menu</Ui> avant d'avoir lié votre compte, le bot vous affiche ces étapes au lieu d'une erreur.

## Que sont les rôles liés ?

Une fois votre compte lié, un serveur Discord peut vous attribuer automatiquement des rôles en fonction de vos données Virtbase :

- <Ui>Serveurs Actifs</Ui> — le nombre de serveurs que vous louez actuellement
- <Ui>E-mail vérifié</Ui> — si votre adresse e-mail est confirmée
- <Ui>Jours depuis l'inscription</Ui> — depuis combien de temps vous êtes client

C'est ainsi qu'une communauté peut attribuer un rôle aux clients de longue date sans que personne n'ait à vérifier quoi que ce soit à la main. Votre adresse e-mail, les noms de vos serveurs et vos adresses ne sont **jamais** partagés avec le serveur Discord — seulement les trois valeurs ci-dessus, et uniquement pour les rôles qu'il est configuré pour attribuer.

Les rôles liés nécessitent l'autorisation `role_connections.write`, qui est demandée lorsque vous liez votre compte. Si vous avez lié votre compte avant que cette fonction ne soit disponible, dissociez-le puis liez-le à nouveau.

## Quelles commandes existent ?

| Commande | Ce qu'elle fait |
| --- | --- |
| <Ui>/menu</Ui> | Le menu principal — tout commence ici |
| <Ui>/help</Ui> | Ce que le bot sait faire, avec des liens vers ce guide |
| <Ui>/invite</Ui> | Un lien pour ajouter le bot à un autre serveur Discord |

Presque tout le reste se fait par boutons. Une fois dans le menu, vous n'avez plus jamais besoin de taper une commande.

## Est-ce sécurisé ?

- Chaque réponse est éphémère : vous seul pouvez la voir, même dans un salon public.
- Le bot agit strictement en votre nom. Il ne peut accéder qu'aux serveurs de votre propre compte, et chaque action passe par les mêmes contrôles d'autorisation que dans le portail client.
- Les actions destructrices — restaurer une sauvegarde, réinstaller, forcer l'arrêt — demandent toujours une confirmation au préalable.
- Les liens de console sont à usage unique et expirent au bout de dix secondes.

## Le bot ne répond pas

Si une commande ne donne rien, vérifiez les points suivants :

1. **Le bot a-t-il l'autorisation de répondre dans ce salon ?** Essayez plutôt en message privé.
2. **Votre compte est-il lié ?** Lancez <Ui>/menu</Ui> — s'il ne l'est pas, les étapes de configuration s'affichent.
3. **Avez-vous lié votre compte avant la mise en place de l'intégration ?** Dissociez votre compte Discord puis liez-le à nouveau sous <Ui>Méthodes d'authentification</Ui>, sur la page [Sécurité](https://app.virtbase.com/account/settings/authentication).

Si rien de tout cela ne vous aide, [contactez notre équipe d'assistance](/fr/contact).
