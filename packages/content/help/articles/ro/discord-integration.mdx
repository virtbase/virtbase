The Virtbase Discord bot lets you manage every server you rent from inside Discord — start and stop them, take backups, edit firewall rules, open a console — without opening the customer portal.

Everything the bot sends is **only visible to you**, even in a shared channel. Nobody else in the server sees your server names, addresses or console links.

## What can the bot do?

| Area            | What you can do                                                                                                |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| **Servers**     | See every server you rent, with its plan, operating system, node and IP addresses                              |
| **Power**       | Start, reboot, shut down, force stop or hard reset, and read live CPU, memory, disk and network usage          |
| **Backups**     | Create, restore, lock and delete backups                                                                       |
| **Firewall**    | Review your rules, add and delete them, and change the default policies                                        |
| **Reverse DNS** | Set and remove the hostname each of your addresses resolves back to                                            |
| **Settings**    | Rename a server, reinstall it with a different operating system, mount an installer image and review your plan |
| **Access**      | Open a one-time console link and reset the administrator password                                              |

Anything that costs money — upgrading a plan, renewing a server — links you through to the customer portal instead. The bot never charges you.

## How do I add the bot to my Discord server?

1. Run **/invite** in any Discord server where the bot is already present, or use the button on your [authentication settings](https://app.virtbase.com/account/settings/authentication) page.
2. Choose the Discord server you want to add it to.
3. Confirm. The bot asks only for permission to send messages and to answer slash commands.

You do not need to add the bot to a server of your own. If it is already in a server you are a member of, you can use it there — or message it directly.

## How do I link my Virtbase account?

The bot cannot tell who you are from your Discord account alone, so the two have to be linked once.

1. Open your [authentication settings](https://app.virtbase.com/account/settings/authentication) in the customer portal.
2. Under **Authentication**, link your Discord account.
3. Go back to Discord and run **/menu**.

That is all. From then on the bot recognises you in every Discord server it is in, and in direct messages.

If you run **/menu** before linking, the bot shows you these steps rather than an error.

## What are linked roles?

Once your account is linked, a Discord server can grant you roles automatically based on your Virtbase data:

* **Active servers** — how many servers you currently rent
* **Email verified** — whether your email address is confirmed
* **Registered days** — how long you have been a customer

This is how a community can give long-standing customers a role without anybody having to check manually. Your email address, server names and addresses are **never** shared with the Discord server — only the three values above, and only for the roles it is configured to grant.

Linked roles need the `role_connections.write` permission, which is requested when you link your account. If you linked before this was available, unlink and link again.

## Which commands are there?

| Command     | What it does                                    |
| ----------- | ----------------------------------------------- |
| **/menu**   | The main menu — everything starts here          |
| **/help**   | What the bot can do, and links to this guide    |
| **/invite** | A link to add the bot to another Discord server |

Almost everything else is a button. Once you are in the menu you never have to type a command again.

## Is it safe?

* Every reply is ephemeral — only you can see it, even in a public channel.
* The bot acts strictly as you. It can only reach servers on your own account, and every action goes through the same permission checks as the customer portal.
* Destructive actions — restoring a backup, reinstalling, force-stopping — always ask for confirmation first.
* Console links are single-use and expire after ten seconds.

## The bot does not respond

If a command does nothing, check the following:

1. **Has the bot got permission to reply in that channel?** Try a direct message instead.
2. **Is your account linked?** Run **/menu** — if it is not, you will see the setup steps.
3. **Did you link before the integration was set up?** Unlink and link your Discord account again on your [authentication settings](https://app.virtbase.com/account/settings/authentication) page.

If none of that helps, please [contact our support team](/en/contact).
